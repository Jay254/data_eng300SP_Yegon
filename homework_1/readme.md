# Homework 1: Aircraft Inventory Analysis
## Running the Code
1. Install dependencies: `pip install pandas numpy matplotlib missingno seaborn scipy scikit-learn`
2. Put the dataset `T_F41SCHEDULE_B43.csv` in the same folder as the notebook.
3. Open `hw1.ipynb` and run all cells from top to bottom.

## What to Expect
The notebook goes through the 6 tasks: investigating and imputing missing data, cleaning messy columns, dropping leftover nulls, applying Box-Cox transformations, creating a SIZE feature from seat quartiles, and building regression + random forest models. Each task has code, plots, and a written summary.
